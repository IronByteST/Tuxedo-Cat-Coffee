# ☕ Tuxedo Cat Coffee

Welcome to **Tuxedo Cat Coffee**, a simple interactive coffee shop web application. This project allows users to browse coffee options, select items, and place an order while viewing their order total.

## 📌 Project Overview

Tuxedo Cat Coffee was created as a web development project to practice JavaScript functions, event handlers, and DOM manipulation.

## 🎯 Learning Objectives

- Create and use JavaScript functions to organize code.
- Use event handlers to respond to user interactions.
- Access and modify DOM elements.
- Dynamically update webpage content and attributes.
- Calculate and display the customer's order total.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git and GitHub

## ✨ Features

- Interactive coffee ordering interface.
- User-friendly layout and design.
- Dynamic order updates.
- Automatic order total calculation.
- Event-driven user interactions.

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Browse the menu and interact with the ordering interface.
